# Local cartridges (`carts/`)

Place your own `.gba` dumps here. This directory is not a ROM warehouse.

- Never commit commercial ROMs or Nintendo BIOS (see `.gitignore`).
- Sidecar battery saves (`.sav`) are gitignored.

Obtain dumps from media you own.

This folder is empty until you add files. A directory path is a smoke run: every `.gba`, `.gb`, and `.gbc` here is logged to `gba-debug.log` as `smoke`, not as `PASS` or `FAIL`. Accuracy ROMs live under `tests/fixtures/`.
